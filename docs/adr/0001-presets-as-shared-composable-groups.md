# Preset 是全局共用、可组合的 skill 分组

用户将 preset 定义为类似整合包的配套 skills 集合。PackCaptain 采用全局共用的 preset 定义，并为每个 target 分别管理启停状态，不采用互斥模式或各项目独立的配置快照。

一个 target 可以同时开启多个 presets。共享 skill 只要仍被任意已开启的 preset 需要，关闭另一个 preset 就不能关闭它。用户仍可单独开关 skill。明确开启整个 preset 时，其全部成员重新开启，不保留阻止本次整组开启的永久手动关闭状态。

修改 preset 后，用户确认将成员变更同步到已开启它的 targets。应用时可选择 agents，并可多选 projects。

同步成员变更时，用户可以选择保持相关成员此前的单项关闭状态，或重新开启这些成员。编辑并同步 preset 不等于明确重新开启整个 preset，不能暗中替用户作出这个选择。

仅在当前同步涉及此前手动关闭的旧成员时显示该选项。TUI 预选保持关闭，但必须经用户确认；选择仅作用于本次同步，不保存成固定偏好。恢复只作用于当前 preset 在所选 targets 下的相关旧成员，不把缺失或不支持的成员当作手动关闭。非交互入口遇到该选择但未收到明确策略时返回影响清单和错误，不执行写入。

这个选择支持在不同项目体验不同作者的技能组合，同时复用同一份分组定义。它决定 preset 身份与 target 状态的边界，日后改成互斥快照会改变已有配置的含义，因此在实现前记录。
